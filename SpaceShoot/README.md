# SpaceShoot 🚀

A 2D space shooter game built with .NET MAUI and C#.

## About

SpaceShoot is a university-inspired project that is being rebuilt from scratch using modern .NET MAUI development practices.

The goal of the project is to create a simple 2D space shooter while learning and applying:

* C#
* .NET MAUI
* Object-oriented programming
* UI development
* Game logic
* Git and GitHub
* Unit testing
* CI/CD
